# SnapSave

SnapSave is a lightweight Windows screen capture utility: choose a capture area, then copy it as PNG or save it as a file.

## Download

Download [SnapSave 1.0.0 for Windows](./SnapSave-1.0.0.exe), then run the EXE directly. No installation is required.

## How to use

1. Launch `SnapSave-1.0.0.exe`; it stays in the Windows notification area.
2. Press the configured capture shortcut (default: `Ctrl+S`).
3. Drag inside the capture frame to move it, or drag a corner to resize it.
4. Click outside the frame: the upper half copies a PNG to the clipboard; the lower half saves a PNG file.

Use the notification-area menu to open Settings or About.
